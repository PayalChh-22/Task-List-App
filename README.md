# 📝 Task List App
A simple and user-friendly **Task List App** built using **HTML, CSS, and JavaScript**.
This app helps users add, manage, and delete their daily tasks easily.

## 🚀 Features
* ➕ Add new tasks
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* 📋 View all added tasks
* 🎨 Simple and clean user interface
* 📱 Responsive design

## 🛠️ Technologies Used
* **HTML** – For creating the structure of the application
* **CSS** – For styling and designing the interface
* **JavaScript** – For adding functionality and handling user interactions
